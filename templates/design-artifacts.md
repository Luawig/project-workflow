# Design artifact shapes

Select a requested output or a decision needing a long-lived owner. Preserve
existing project structure.

## Product definition

```md
# Product definition
## Goal and users
Describe the outcome and audience.
## Scope
Reference the requirement owner; state non-goals.
## Scenarios and acceptance
Link success, boundary and failure criteria.
## Unknowns
State consequential assumptions and who can resolve them.
```

## Architecture decision

```md
# Architecture decision
## Status
proposed
## Drivers
Link constraints and prioritized quality scenarios.
## Boundaries
Identify responsibilities, exclusions, data ownership and trust boundaries.
## Alternatives
Compare viable options against drivers, including the smallest change.
## Decision
State choice, applicability and authority.
## Evidence
Record probe, failure criterion, observed result and limitations.
## Consequences
State costs, residual risks and reconsideration trigger.
## Verification and recovery
Link acceptance, failure detection and rollback or forward repair.
## Related decisions
Link superseded/supporting decisions without rewriting history.
```
